Steps in the task files use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the fourteen designed pages of jobsadmire.com (TR at the root, EN under `/en`) onto the finished WP1 + WP2a foundation on `wp2/foundation`; wire every form to the Operations intake door (catalog v1.1, live on Operations `main` 47a2160); prove each page with the gate (axe at zero, LCP ≤ 2,500 ms and performance ≥ 0.95 as medians under DevTools throttling, the 204,800 B JS ceiling, the pixel harness for the four D27 pages); run the forms end-to-end on `staging`; leave `gate:launch` green on every route in both locales with `UNBUILT_PATHNAMES` empty — the state Gate A (spec §5) and the WP7a cutover start from.

**Architecture:** Everything stays inside the WP1/WP2a shape: server components by default, `'use client'` islands imported by module path and loaded on interaction or in view (`LazyIsland`, `next/dynamic`); package strings by exact id through `makeT`/`makeTf` (D17 metric placeholders), composed copy under `sys.<page>.*` in both locale files; data through the LOCAL bundle (`getBundle`, `getCollection`, `getMetric`, `getRateConfig`, `getOffice`, `getPageSeo`) — fixtures never in production (D23); forms through the kernel (`createFormAction` + `FormShell`/`Field`, success → `/tesekkurler?form=<key>`, the visitor fallback panel on every non-success, door-less previews except `staging` — W92); chrome through the route groups `(site)/(minimal)/(bare)` with per-route CTAs (`CTA_BY_PATHNAME`/`DEFAULT_CTAS`) whose anchor ids the pages must render; SEO through `buildMetadata`, `pageOgImageUrl`, `articleJsonLd`, `jobPostingJsonLd`; the calculator through the pure engine `src/lib/calculator/` and `COPY_DELTAS`; security headers from the middleware (nothing for pages to do — W157/W160).

**Tech Stack:** Next 16.3.5 (App Router, RSC, server actions, `next/og`), React 19, TypeScript strict, Tailwind 4, next-intl 4.14.5 (`as-needed`, TR root), Zod 3, Vitest 4 + Testing Library, Playwright + axe + Lighthouse CI (`npm run gate`, `npm run gate:launch`, `npm run js-size`, `npm run pixel`), `tsx` scripts; Operations side NestJS 10 (the door, read-only for this plan).

**Spec:** `docs/superpowers/specs/2026-09-18-website-programme-design.md` (approved v3; §3.1, §5 WP2, D2, D9, D11, D13–D18, D20, D22, D26–D27, §10). **Rulings:** `docs/superpowers/plans/2026-09-20-wp2-rulings.md` — W1–W23 planning, W24–W57 WP2a reconcile, W58–W72 open items, W73–W76 and W116–W161 execution rulings (BINDING facts about the built foundation; every page obeys W118–W161), W77–W115 the WP2b reconcile rulings, W162+ the residual rulings from the reconcile rechecks; WP1 rulings R1–R60 where cited. **Foundation facts:** `docs/superpowers/handoff-2026-09-25/wp2-planning/wp2a/produces-final.md` (Produces blocks + `## Task N — as built` sections — an as-built section beats the frozen block; the CODE beats both), `wp1-foundation-as-built.md`, `operations-door-contract-as-built.md`, website `docs/INTEGRATIONS.md` I4 (catalog v1.1).

## Global Constraints

- **Memory rule (owner, binding):** one heavy job at a time on this machine; verify = `npm run typecheck && npm run lint && npm run format && NODE_OPTIONS=--max-old-space-size=4096 npx vitest run --maxWorkers=1` at EVERY commit (never `npm run verify`, `npm test` or `npm run e2e`); every task ends with ONE `NEXT_BUILD_CPUS=2 NODE_OPTIONS=--max-old-space-size=4096 npm run build`, ONE `npm run start`, ONE `E2E_BASE_URL=http://localhost:3000 npm run gate`, `npm run js-size`, the pixel harness for the D27 pages only (W126); kill the server afterwards and check for stray `node`/`next` processes; at most 4 concurrent agents in total, Opus only where a task file or a review needs it.
- **Branch discipline:** all work on `wp2/foundation` in the worktree `jobsadmire-website-wp2` (Vercel previews only, auth-protected; the gate needs the bypass header — W137 — and the report folders `.lighthouseci/`, `lighthouse-report/`, `.pixel/`, `playwright-report/`, `test-results/` are deleted after a preview run because they hold the secret); website `main` is untouched until the WP7a cutover; never `git stash`; never rewrite a pushed commit (W118); push `wp2/foundation` after each reviewed task (owner decision 2026-09-26); the `staging` branch is fast-forwarded to `wp2/foundation` before T14.
- **Code rules every page obeys:** imports by module path — `@/design/primitives/<Name>`, `@/design/blocks/<Name>`, `@/design/islands/<Name>`, `@/lib/format/date/<fn>` — never the barrels (W125/W130/W134/W147/W156); `contactKindOf` from `@/analytics/contact-kind` in server code, `ContactLink`/`useContactClick` only in `'use client'` code; never `hidden` with an unprefixed display utility, never one property twice at one variant, a different look is a Button VARIANT (W119/W122/W155 — the static scan fails the gate); `ImageSlot` owns its box (W129); `LazyIsland({ load, props, fallback, rootMargin? })`, no `ssr` prop (W132); the `CLIENT_SYS` allowlist grows with every client-read `sys.<ns>` (W148); the voice rule over all `sys.*` (W154 — "JobsAdmire", never "we"/"biz"); no `<main>` in a page (the group layout owns it); `data-testid="page-h1"` on the single h1, `data-lcp-slot` on the named LCP element, `data-placeholder="<slot>"` on every placeholder (D26/W55); the anchor ids the route's `CTA_BY_PATHNAME`/`DEFAULT_CTAS` entry names are rendered (W152/W158 — `gate:launch` sweeps dead targets); `revalidate = 86400` when a D17 dated badge is mounted (W150); own-page breadcrumb ids (W109); the route leaves `UNBUILT_PATHNAMES` and its two locale paths join `GATE_ROUTE_TABLE` in the same task.
- **Forms:** field names exactly the Ops catalog v1.0 + v1.1 (`city` ≤120 on hire/workers/partner/callback/contact, `partner.track`, `contact.topic`, `careers.portfolioUrl` — `docs/INTEGRATIONS.md` I4); wire values are keys (W77); `consent: 'checkbox'` (W79) with `/privacy` as the only consent link; `START_WHEN_KEYS` (W78); package labels passed as `label` (W115); distinct `idScope` when two shells share a key; uploads ≤ 3 MiB, one file per server-action call (W73/W116); no visitor data in any DOM href — the WhatsApp fallback URL is composed at click time (W76/W95); every success path is `/tesekkurler?form=<key>` (D13); the page e2e is deterministic without `OPS_API_URL` (the fallback panel appears after submit).
- **Budget and proof:** `resource-summary:script:size` ≤ 204,800 B per gate route, the 194,560 B lazy-loading line (W120/W136 — the ledger records `npm run js-size`); LCP ≤ 2,500 ms and performance ≥ 0.95 as medians of 3 runs under DevTools throttling (W145); axe at zero and the width sweep clean on every route; the pixel harness (390/900/1440, two-iteration cap — `2026-09-20-wp2-pixel-harness.md`) for Homepage, Hire Workers, Cost Calculator and Blog Article only.
- **Copy:** package strings by exact id (never invent one; the six deliberately-empty TR ids render empty); new copy only under `sys.<page>.*` (or an existing `sys.form.*`) in BOTH `src/messages/tr.json` and `en.json`, formal Turkish "siz" register, natural marketing English; `sys.seo.<pageKey>.{title,description}` where the package has none; metric figures only through `makeTf` (D17) and calculator figures only from the engine/`COPY_DELTAS` (W142/W143) — never the design's sample numbers.
- **Docs in the same commit:** `docs/SEO.md` page row (incl. the named LCP element), `docs/ANALYTICS.md` (events, allowlists), `docs/CONTENT-MODEL.md` (sys namespace line), `docs/PRD.md` where a documented behaviour changes, `docs/INTEGRATIONS.md` I4 table finalised in T14 (both repos checked); the website `CLAUDE.md` checklist applies to every task.
