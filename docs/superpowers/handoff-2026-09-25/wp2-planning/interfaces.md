# WP2a foundation — interface skeletons the writers MUST converge on (controller, 2026-09-20)

These are the names, paths and signatures every WP2a task produces and every WP2b page consumes. A writer may refine a type body or add an optional field, but may not rename, move, or change the shape of anything listed here without saying so in the task's "Produces — deviations" line. Existing WP1 APIs (see the as-built note) are used as they are.

## T0a Forms kernel — `src/forms/`
- `src/forms/consent.ts`: `export const CONSENT_VERSION = 'kvkk-2026-09' as const;` (≤40 chars, the single site-wide value sent as `consentVersion`).
- `src/forms/wire.ts` (pure, unit-tested): `export type WireFields = Record<string, string | string[]>; export type WireEnvelope = { locale: Locale; consentVersion: string; captchaToken?: string; honeypot?: string; sourcePath?: string; fields: WireFields }; export function buildEnvelope(input: { locale: Locale; fields: WireFields; captchaToken?: string | null; honeypot?: string | null; sourcePath?: string | null }): WireEnvelope` — drops empty strings/undefined from `fields`, never sends `consentVersion` other than `CONSENT_VERSION`.
- `src/forms/post.ts` (`import 'server-only'`): 
  ```ts
  export type PostFormOk = { kind: 'ok'; id: string; status: 'RECEIVED' | 'HANDLED' | 'FAILED' | 'SPAM'; isTest: boolean; replayed: boolean; captchaDegraded: boolean; error: string | null };
  export type PostFormResult =
    | PostFormOk
    | { kind: 'invalid'; message: string }            // 400 — catalog/DTO rejection (should never happen after client validation)
    | { kind: 'captcha' }                              // 403 — Turnstile failed/missing
    | { kind: 'off' }                                  // 404 — module off or form inactive (newsletter in Phase A)
    | { kind: 'tripped' }                              // 429 — form tripped, fallback 'whatsapp'
    | { kind: 'unauthorized' }                         // 401 — token misconfigured (ops alarm, visitor sees 'unavailable' copy)
    | { kind: 'unavailable'; cause: 'network' | 'timeout' | 'server' }; // no response / 5xx after the one retry
  export async function postForm(formKey: FormKey, envelope: WireEnvelope, visitor: { ip: string | null; ua: string | null }): Promise<PostFormResult>
  ```
  URL `${OPS_API_URL}/api/website/v1/forms/${formKey}`; headers `Authorization: Bearer ${OPS_WEBSITE_WRITE_TOKEN}`, `Content-Type: application/json`, `X-Website-Visitor-Ip`, `X-Website-Visitor-Ua`; `cache: 'no-store'`; per-attempt `AbortSignal.timeout(4000)`, at most ONE retry and only for network/timeout/5xx (W3: total ≤ 8 s); a missing `OPS_API_URL`/token returns `{kind:'unauthorized'}` without a network call.
- `src/forms/action.ts` (`'use server'` factory, server-only):
  ```ts
  export type FormActionState =
    | { status: 'idle' }
    | { status: 'error'; result: Exclude<PostFormResult, PostFormOk> | { kind: 'failed'; error: string | null }; values: Record<string, string> }
    | { status: 'fieldErrors'; errors: Record<string, string>; values: Record<string, string> };
  export type FormSpec<S extends z.ZodTypeAny> = { key: FormKey; schema: S; toFields: (parsed: z.infer<S>) => WireFields; };
  export function createFormAction<S extends z.ZodTypeAny>(spec: FormSpec<S>): (prev: FormActionState, data: FormData) => Promise<FormActionState>
  ```
  Reads `locale` from `getLocale()`, `sourcePath` + visitor ip/ua from `headers()` (`x-forwarded-for` first hop, `user-agent`, `referer` path), `cf-turnstile-response` and `honeypot` from the FormData; Zod errors → `fieldErrors` with `sys.form.errors.*` keys; `ok` with `status !== 'FAILED'` (RECEIVED/HANDLED/SPAM/replayed all count) → `redirect({href: {pathname: '/thank-you', query: {form: spec.key}}, locale})` from `@/i18n/navigation`; `ok` + FAILED → `error` with `{kind:'failed', error}`; every other kind → `error`.
- `src/forms/client/FormShell.tsx` (`'use client'`): 
  ```ts
  export type FormShellProps = { action: (prev: FormActionState, data: FormData) => Promise<FormActionState>; formKey: FormKey; locale: Locale; turnstileSiteKey: string | null; whatsappNumber: string; whatsappText: (values: Record<string, string>) => string; submitLabel: string; consentLinkHref?: '/privacy'; title?: string; children: ReactNode; className?: string; testId?: string };
  export function FormShell(props: FormShellProps): JSX.Element
  ```
  Renders `<form action={formAction} noValidate>` with `useActionState`, `{children}` (the page's `FormField`s), the honeypot (`<input name="honeypot" tabIndex={-1} autoComplete="off" aria-hidden className="absolute -left-[9999px]">`), `<Turnstile siteKey>` when the key is non-null, the consent checkbox (`name="consent"`, required, `sys.form.consent.label` with the privacy link), the submit `Button` (pending state from `useFormStatus`), and `<FallbackPanel>` when `state.status === 'error'`; field errors are passed down through `FormErrorsContext` (`useFieldError(name)`), so pages' `FormField`s show `sys.form.errors.*` text.
- `src/forms/client/Turnstile.tsx` (`'use client'`): `export function Turnstile({ siteKey, locale }: { siteKey: string; locale: Locale }): JSX.Element` — loads `https://challenges.cloudflare.com/turnstile/v0/api.js?render=explicit` once with `next/script` (`strategy="lazyOnload"`), renders the widget into a div, appearance `interaction-only`, writes the token into `<input type="hidden" name="cf-turnstile-response">`; re-renders on error/expiry.
- `src/forms/client/FallbackPanel.tsx` (`'use client'`): `export function FallbackPanel({ result, values, formKey, locale, whatsappNumber, whatsappText }: { result: FormActionState extends infer S ? Extract<S, {status:'error'}>['result'] : never; values: Record<string,string>; formKey: FormKey; locale: Locale; whatsappNumber: string; whatsappText: (values: Record<string,string>) => string }): JSX.Element` — role="alert", headline + body from `sys.form.fallback.<kind>.{title,body}` (kinds: captcha, off, tripped, unauthorized, unavailable, failed, invalid), WhatsApp `Button` (primary when kind is tripped/unavailable/unauthorized/off, secondary otherwise) with `waLink(whatsappNumber, whatsappText(values))`, tel + mail links from `bundle.settings` passed through props; fires `track('whatsapp_click', {page, locale, placement: 'form_fallback'})` on click and `navigator.sendBeacon('/api/form-beacon', JSON.stringify({formKey, kind, page}))` once on mount.
- `src/app/api/form-beacon/route.ts`: `POST` → validates `{formKey: FormKey, kind: string, page: string}`, `console.error('[form-beacon]', json)`, increments an in-memory counter exported as `formBeaconCount()` for site-health; `204`.
- `src/app/api/site-health/route.ts` extended: `ops: { state: 'ok' | 'off' | 'unauthorized' | 'unreachable'; latencyMs: number | null }` from `GET ${OPS_API_URL}/api/website/v1/ping` (Bearer write token, 3 s timeout) and `formBeacons: number`.
- `src/messages/{tr,en}.json` gain `sys.form.*`: `labels.{name,email,phone,company,city,country,sector,headcount,startWhen,roleNeeded,message,subject,iAm,preferredTime,cv,consent}`, `placeholders.*`, `hints.*`, `errors.{required,email,phone,min,max,url,file,consent,captcha}`, `consent.{label,link}`, `submit.{default,sending}`, `honeypot`, `fallback.<kind>.{title,body}` ×7, `fallback.{whatsapp,call,email}`.
