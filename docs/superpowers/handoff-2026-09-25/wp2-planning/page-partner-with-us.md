## traps
- `partner` catalog has NO iAm/track field: the door drops any `iAm`/`track` you send and the handler classifies every partner submission SOURCING_PARTNER → HR-agency applications auto-assign to the Pakistan team (website-form-catalog.ts:64–67, website-inquiry.logic.ts:16–20, PRD §5.1 rules). Either send the HR track as formKey `hire` with iAm=hr_agency (then the hire autoresponder/thank-you line fire) or change the catalog in Operations first — decide before wiring.
- `country` is REQUIRED and must be ISO-2 at the door; the design has no country field for HR (send 'TR'), free text for agent ('Pakistan' → 400) and 'City, country' for institute — build an ISO-2 select from a country list that does not exist in the bundle yet.
- `city` (HR) is not in the catalog and is dropped silently (`dropped`, no error) — fold it into `message` or it never reaches the inbox.
- The sourcing-partner form's checkbox is a licence declaration (partner.114), not KVKK consent; the door still requires `consentVersion` — add the KVKK line (partner.090/091) to that form or you record consent nobody gave.
- Hero/logo numbers (5, 20, 12, 470, 25) are `data-target` markup attributes, not strings: they are absent from partner.json and the string import — they only exist if you create the metric data; partner.077 '12+' and partner.159 '470+' hard-type them in copy (D17 lint exists but is unwired).
- partner.059 promises 'one business day' while four other ids promise '4 working hours' on the same page — do not ship both; owner input #2 default is 4 working hours.
- partner.162/163 TR values 'İndirin' break the 'store micro-copy stays English' rule; the same translated pair exists on six other pages — needs a package-level override, not a per-page hack.

- Design inline success banners are replaced by navigation to /tesekkurler?form=partner (D13) — three forms, one key: the conversion dedupe is per form+path, so three submissions from this page count as one conversion per session unless the key or path differs.
- track() throws on unknown event names — the design's partner_track_select / partner_application events must not be ported as-is.
