## traps
- The `hire` catalog requires `email` and `name`; the homepage design has no email input and hides `person` on phones — wiring 'as designed' yields a 400 on every mobile submit. Resolve before building, not in the fallback panel.
- `fields.city` is silently dropped by the door (unknown keys go to `dropped[]`, no error) — a submitted city vanishes with no test failure.
- Callback mode is NOT free: under formKey `callback` only name/phone/email/preferredTime/topic survive; under `hire` the callback intent is lost unless encoded in `message`.
- Ticker and pool content look like data but are fabricated in the design (`cases`, `POOL`, computed 'JA-10xx' refs and 'N days ago'); `stories`/`pool` are FIXTURE_ONLY and throw in production under LOCAL (pure.ts assertServableInProduction).
- `makeT` throws on unknown ids outside production — every `{{ t.x }}` must be resolved to a real home.NNN; five dictionary keys (slimLic, footLic, hintText, hintCta, dashStore) have NO homepage id (use hire.019, calc.419, sys.languageHint.*, hire.240/241).
- Computed labels (headcount chips, 'Not applicable', '1.5× legal floor', season ranges/headlines, 'monthly payroll') need new `sys.*` messages via getTranslations('sys'), never invented `home.3xx` ids (CONTENT-MODEL §sys).
- The design's `iso` map (13 countries) and source-map.js (12) disagree; copy says 13 — build one list and derive both count and map from it.
- Teaser rounding: 33030×1.5 = 49,545 vs the full calculator's ceil-to-500 = 50,000; a shared engine must pick one or the two pages disagree by 455 ₺ next to identical copy.
- The count-up reads numbers from `data-count` attributes in the design; Stat primitive takes `value` — metrics must come from data (WebsiteMetric), not from the string catalogue, or the D17 lint fails.
- Desktop values in the design are 1.333× (zoom 0.75) — port ×0.75 (D19) and never the ≤1100 values; 460/560/900 breakpoints are 1:1.
- README's nav order differs from the homepage markup — chrome is already built; do not re-derive nav from this page.
- `sec` groups are unreliable for bulk APPROVE: legal footer line home.228 sits under 'Sezon planlayıcı', process chips home.224–227 under 'Alt bilgi (Footer)', ticker strings split between 'Adaylar' and 'Onay panosu'.
- Design bodies at lines 962/987 are hard-coded 'We handle…' English; the package strings home.145/153 say 'JobsAdmire handles…' — use the strings (formal register rule).
- Every deploy of Operations is a 30–60 s 502 on /api/website/*: the server action must retry non-2xx and rely on the hour-bucket dedupe; identical payloads within the hour replay the first row (no second inquiry, `replayed:true`).
- `newsletter` is inactive (404) by design; irrelevant here but the same door answers 404 for `module off` — the fallback panel must not present a 404 as a visitor error.
