## traps
- blog-posts.js `date` and `read` are locale-formatted display strings, not data — do not parse them at render time; the import must convert to ISO + readMinutes and format per locale (no date formatter exists in src/lib/format).
- JA_BLOG_FIND returns P[0] for an unknown slug (blog-posts.js:43) but Blog Article.dc.html:1023 renders 'Article not found' — follow the page, return 404 (notFound()) for unknown slugs, never the first post.
- The '≈ N min left' widget multiplies a hard-coded 8 by progress (Blog Article.dc.html:1055) — use the post's own read time.
- Share URL and the Work Permit/Homepage teaser links hard-code https://www.jobsadmire.com/blog… — build from SITE_URL + locale-aware getPathname (EN lives under /en).
- Blog.dc.html carries its own copies of the post data (postsEn/postsTr/featuredByLang/mostReadByLang) that drift from blog-posts.js (the TR slug contradiction at line 923) — import from blog-posts.js once and derive featured/most-read from record flags.
- The one written body is hard-coded HTML inside Blog Article.dc.html (lines 540-662), not in blog-posts.js; its TR text exists only as blogarticle.025–076 strings — converting it to Markdown must keep the key-takeaways box, the 2-up rule cards, the checklist grid, the numbered steps, the warning box, the quote CTA and the FAQ as structured fields, or the TR body is lost.
- `/blog` and `/blog/[slug]` are literal locale-shared pathnames at the Turkish root; never add a /blog redirect or a /blog/ 410 prefix (docs/redirects.md:36-40) and never redirect '/' or '/blog'.
- Design h2 headings double as toggle buttons on mobile and the h1 rotates text every 2.6 s — port neither literally (D20: Accordion with headingLevel=2; a stable h1 with an optional paused ticker).
- Newsletter formKey is inactive by default and the door 404s inactive forms; a naive server action would show the visitor a failure on every submit in Phase A — decide hide vs fallback before wiring, and never buffer leads on Vercel (D11).
- The FIXTURE_ONLY_COLLECTIONS guard covers pool/stories/representatives only — a `blog` collection served from LOCAL in production is allowed, but only written articles may render (CONTENT-MODEL v1 rule).
- blog.095 / blog.085 / blogarticle.032–034 are position-dependent fragments; render them via an interpolated message per locale, not by concatenating t(id) in source order.
- Every desktop pixel value in the design is authored at 1.333× (zoom 0.75) — normalise per D19 (e.g. the 430px cover, 270px featured cover, 190px card cover are 322/202/142 CSS px on screen); ≤1100px values are 1:1.
