- '+19 days' (051) is the one KPI value stored as a string; the other three KPI numbers and all four hero numbers are markup-only — the numbers-out-of-copy lint will not catch them, a metrics model must replace them.

- monthLabel is en-GB hardcoded; TR strings for roles/countries exist only for the sample values (112–123) — a real feed's free text will not be translated at runtime.
- Mobile ≤700px is a different layout, not a reflow (slider + nth-child hiding + thumbnail rows); a naive responsive grid will duplicate the first 3 cards.
- waHireHref hardcodes 905011240340 (line 1088) while ctaWaHref uses props.whatsappNumber — use bundle.settings.whatsappNumber for both.
