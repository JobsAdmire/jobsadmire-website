- about.json's sec groups do not follow the page: 'Menü ve genel etiketler' (about.001–.031) mixes chrome labels with the hero's breadcrumb, h1, lede, pill labels and CTAs; 'Kapanış çağrısı' (about.110–.141) mixes the green CTA with the entire footer, the WhatsApp prefill and the dead subscription strings; about.142–.145 are appended after the footer under three different secs. Do not scope work or bulk-approve by sec on this page.
- '2025' (timeline label, :703), '98%' (:734), '2024' (year badge, :625), '470+/14+/12+' (hero pills, :532-541), and both bespoke WhatsApp prefills (:775, :914) exist ONLY in markup — the string catalogue is not the full copy inventory for this page.
- The founder quote wraps a live number across three ids (about.048 / about.143 / about.049); TR reads correctly only because the TR of about.048 ends on 'Bugün' and about.143 is 'aile' — a naïve concatenation with EN spacing rules will break the Turkish sentence.
- The page has no form, so 'wire every form to WP3a' is a no-op here — but every CTA still needs the thank-you/conversion-page-free analytics events (call_click/whatsapp_click/email_click with placement) and internal Link targets, not the old absolute https://www.jobsadmire.com/#request-form URLs (:715, :913).
- '/profile/' is a 410 prefix (redirects/gone.json:3): porting the design's PDF href verbatim ships a dead link; the same goes for hot-linked https://www.jobsadmire.com/logos/iskur.png and /logos/logo4.png once the old site is aliased away.
- The Stat primitive appends `suffix` after formatInt — passing '%' yields '98%' in Turkish where D18 requires '%98'; passing 'days' yields '45days' with no localisation. Handle these two by hand or extend Stat before using it for the 4-stat row.
- The design's mobile CSS deletes content (feature bodies :336, office contacts :361, tech visual :305, green CTA paragraph :374) rather than restyling it; a Tailwind port that hides with `hidden md:block` keeps it in the DOM (fine for SEO) but a port that omits it changes the content per breakpoint — pick deliberately.
- Both office cards link the Turkish WhatsApp number and info@ — do not 'fix' the Karachi card with an invented Pakistani number; it is an owner input.
- The demoVideoUrl prop renders an autoplaying video with no controls (:1123-1127); if ever enabled it needs D20 pause/play — default it off.
- Desktop values in the design are authored at zoom 0.75 (About Us.dc.html:14; README 'Read this before measuring'); About is a side-by-side review page (D27), so normalise per D19 rather than porting px verbatim.
