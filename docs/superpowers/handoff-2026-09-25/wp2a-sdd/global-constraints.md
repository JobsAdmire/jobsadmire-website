## Global Constraints

- `npm run verify` (tsc, eslint, prettier --check, vitest) must be green at EVERY commit — it runs inside the Vercel build; a red commit is a red preview.
- Never import `design-package/**` or `src/content/local/*` from `src/**` (R56/D23); `scripts/` may. `src/content/local/*.json` are generated by `npm run content:import` and never hand-edited. The frozen contract `contract/website-bundle.v1.ts` is not modified (hash-pinned; Ops vendors it).
- Package strings only by exact id through `makeT`/`t()`; every new copy is a `sys.*` key present in BOTH `src/messages/tr.json` and `src/messages/en.json` (W9/W23); never invent a package id; never read `sys.*` through `t()`.
- Server-only secrets: `OPS_WEBSITE_WRITE_TOKEN`, `OPS_WEBSITE_TEST_TOKEN`, `OPS_API_URL` are read only in `server-only` modules; the browser never calls Operations (D6); no CORS change.
- Accessibility over pixel fidelity (D20): real inputs with labels and `role=alert` errors, focus management, reduced-motion fallbacks, contrast tokens; the width sweep (1440…390) and axe stay at zero on every gate route.
- JS: `resource-summary:script:size` ≤ 204,800 B on every gate route (W13 amended); heavy islands load on interaction/viewport via `next/dynamic`.
- No runtime fetch to any third party except GTM/Turnstile (W14): maps, flags, QR, fonts, logos are local or build-time.
- Website `main` is currently the production branch of the live Vercel project: all WP2 work lands on `wp2/foundation` (previews only); nothing is pushed to `main` until the owner has moved the production branch (memory note 2026-09-20).
- Operations `main` is production in ~2 minutes; the one Ops task ships behind the still-off `WEBSITE_MODULE_ENABLED` flag, with the WP3a push recipe (`docs/DEPLOYMENT.md` § Flipping / § Deploy pipeline), boot conformance at 0 and `PERMISSION_KEYS_HASH` untouched.
- One heavy job at a time on this machine (`jest --maxWorkers=2`, one `next build`, one Playwright run); reviews may run in parallel.
- Task order: 1 data layer → 2 forms kernel → 3 chrome → 4 SEO → 5 primitives/blocks → 6 islands/assets → 7 gate tooling → 9 calculator engine → 8 Operations catalog (the Ops task runs last because it deploys to production and needs its own worktree, W47); Tasks 1–7 and 9 are serial on `wp2/foundation`.
- Every task updates the docs it touches in the same commit (ARCHITECTURE, CONTENT-MODEL, SEO, ANALYTICS, INTEGRATIONS, DEPLOYMENT, PRD) — the website `CLAUDE.md` checklist applies.
